# Fortune & Flow

English-language finance literacy site blending modern money education with Chinese zodiac and metaphysics cultural context.

## Monetization
- Google AdSense / Mediavine (display ads)
- Affiliate links (insurance, brokers, fintech SaaS — 20-50% recurring commissions)
- Future: paid digital products

## Content Pipeline
1. Keyword research (Ahrefs free / Google Keyword Planner) — target 100-1000 monthly searches, low competition
2. AI-generated drafts (Grok/Claude) around one keyword per article, 800-1200 words
3. Human review pass — remove predictive/absolute claims, add affiliate links naturally
4. TikTok/Shorts distribution via Seko/HeyGen avatar pipeline
5. Monitor which keywords convert; double down

## Compliance
- Privacy policy + disclaimer pages included
- AI-generated content labeled per platform requirements
- No financial predictions; educational framing only
- Affiliate disclosure on all monetized pages

## Stack
- Static HTML/CSS (no build step)
- Deployable to Netlify, Vercel, GitHub Pages, or Cloudflare Pages
- WordPress migration path available if CMS needed later
